# UCAS演示文稿生成器

## 简介

本项目为中国科学院大学（UCAS）风格的演示文稿生成工具，提供完整的Claude Code Skills配置，支持生成符合中科院标准的HTML格式PPT。设计风格参考官方模板，采用专业的深蓝色主题和清晰的层次结构。

## 文件结构

```
ucas-presentation-ppt-generator/
├── Skill.md              # Claude Code Skills核心配置文件
├── README.md             # 使用说明文档
└── references/
    ├── CAS_logo.png      # 中国科学院院徽（需用户提供）
    ├── UCAS_logo.png     # 中国科学院大学校徽（需用户提供）
    └── template.html     # 演示模板文件
```

## 快速开始

### 步骤一：准备Logo文件

请将以下两个Logo文件放入你的文件夹中：

- **CAS_logo.png**：中国科学院院徽，用于首页左侧蓝色竖幅区域内
- **UCAS_logo.png**：中国科学院大学校徽，用于内页右上角


### 步骤二：使用Skills生成PPT

在Claude Code中激活此Skills后，您可以通过以下方式生成演示文稿：

1. **提供基本信息**：告诉Claude您的演示主题、演讲者信息、内容大纲等

2. **指定页面需求**：说明需要生成的页面数量和每页内容要点

3. **获取HTML文件**：Claude将根据规范生成完整的HTML演示文稿

### 步骤三：查看和使用

1. 使用浏览器打开生成的HTML文件
2. 按F11进入全屏模式
3. 使用键盘方向键或空格键翻页

## 设计规范

### 主题蓝色

本演示文稿使用专业的深蓝色作为主题色，品牌识别度更高：
- **主题蓝色**：`#18388A`
- **强调红色**：`#CC0000`
- **背景色**：纯白色

### 首页布局

首页采用非对称两栏式布局，与参考图片风格一致：
- 左侧蓝色竖幅（宽度约32%），使用#18388A背景色
- 右侧内容区域（宽度约68%），采用左对齐布局
- CAS院徽位于左侧蓝色区域内，垂直居中
- 标题和汇报人信息使用#18388A色

### 内容页布局

内容页采用清晰的纵向布局结构：
- 右上角放置UCAS校徽
- 标题使用左侧蓝色边框装饰（而非底部横线）
- 内容左对齐，列表使用实心黑点
- 右侧边距充足，视觉舒适

### 字体规范

- **主字体**：微软雅黑（Microsoft YaHei）
- **首页主标题**：48px，粗体
- **首页副标题**：26px，常规字重
- **内容页标题**：32px，粗体，左侧蓝色边框
- **正文内容**：20px，常规字重
- **小节标题**：22px，粗体

### 强调样式

- **红色强调**（#CC0000）：用于关键结论、重要数据、核心发现
- **加粗标注**：用于专有名词、术语、重要概念
- 每个页面建议使用红色强调不超过2-3处

## 打包和部署

### 打包说明

1. 确保文件夹名称为`UCAS_presentation_PPT`
2. 确认logo文件已放入resources文件夹
3. 压缩整个文件夹为ZIP文件（根目录为UCAS_presentation_PPT文件夹）

### 上传到Claude Code

1. 打开Claude Code设置
2. 进入Skills管理页面
3. 点击添加新Skill
4. 上传ZIP文件
5. 启用该Skill

## 常见问题

### Q1：字体不显示为微软雅黑怎么办？

请确保您的系统已安装微软雅黑字体：
- Windows：系统自带，无需额外安装
- macOS：系统可能显示为PingFang SC
- Linux：可使用以下命令安装：`sudo apt-get install fonts-wqy-microhei`

### Q2：Logo图片不显示怎么办？

请检查：
1. Logo文件是否正确放置在resources文件夹
2. 文件名是否为`CAS_logo.png`和`UCAS_logo.png`
3. 文件路径是否正确引用
4. 图片格式是否为PNG且背景透明

### Q3：如何调整页面颜色和样式？

您可以修改CSS样式部分：
- 主题蓝色：`#18388A`（可搜索替换）
- 强调红色：`#CC0000`（可搜索替换）
- 字号大小：根据需要调整数值

### Q4：可以导出为PDF或PowerPoint吗？

当前版本输出为HTML格式。如需PDF：
1. 使用浏览器打开HTML文件
2. 打印为PDF（Ctrl+P，选择保存为PDF）
3. 注意选择"背景图形"选项以保留颜色样式

### Q5：首页布局如何调整？

首页采用非对称两栏布局，如需调整可修改以下CSS类：
- `.title-sidebar`：左侧蓝色竖幅区域
- `.title-content`：右侧内容区域
- 调整`width`属性可改变两栏比例
